# Split the framework and the example system into separate repositories

Supersedes ADR 0001. The example system moved to its own repository, [gohex-example](https://github.com/akaporn-katip/gohex-example), with fresh history; this repo now holds only the framework libraries, flattened from `libs/<name>` to `<name>/` at the root so module paths read `github.com/akaporn-katip/gohex/<name>`. Each module is released with a `<name>/vX.Y.Z` tag; the pre-release `replace` directives are gone and intra-repo requires pin real versions — so external projects can `go get` any module. Chosen over staying a monorepo to make the consumable surface unambiguous (everything here is importable; the example is a consumer like any other), accepting that cross-repo changes now need a lib release before the example can pick them up (mitigated during development by an untracked `go.work` overlay spanning sibling checkouts).
